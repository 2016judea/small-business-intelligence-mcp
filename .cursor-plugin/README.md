# Brick & Mortar Public Records

Ask about a building in the Twin Cities and get an answer from the record instead
of a guess.

Twelve read-only tools. Two read 25 joined datasets of Minneapolis–St. Paul public
records — 1,575,384 rows of parcels, recorded sales, assessor values, business
licences, building permits, inspections, emergency calls, contamination sites,
flood zones and wages. Nine more are research frameworks that work in any US
metro: tear down one business, map a competitive set, benchmark local pricing, or
find which public record answers a question in a city we don't hold. The twelfth
sends us a feature request.

**Free, no account, no key, nothing to sign in to.** The underlying files are
CC BY 4.0 and downloadable at
[brickandmortar.dev/datasets](https://brickandmortar.dev/datasets).

## Install

The plugin points Cursor at a hosted remote server over Streamable HTTP. There is
nothing to run locally and no credential to supply.

```
https://brickandmortar.dev/mcp
```

## What it answers

- **A property question, from the record.** What a building last sold for, what
  the assessor values it at, which permits have been pulled on it, which licences
  are active at an address.
- **A local market, before money is committed to it.** Business counts by trade
  across five vintages, wages, building stock by era, recorded sale prices per
  square foot.
- **What a lender or a buyer will ask about a site.** Contamination sites, flood
  zones, inspections and emergency-call volume around a parcel.

Coverage is not uniform and every answer says so rather than averaging: it runs
from one county to all seven of the Twin Cities metro.
